Orion UI is a **comprehensive, free, open-source shadcn-based registry**. Components, full app
sections, and marketing blocks — installable with the shadcn CLI, customizable because you own
the code.

## Principles

1. **Comprehensive, not agentic.** AI app UI ships first (wave 1) — the library covers everything.
2. **Free forever.** MIT, no paywalled tiers.
3. **Benchmarks or it didn't happen.**
4. **TDD.** The test is written before the component. Every run. No exceptions.
