## Install

```bash
npx shadcn@latest add https://orion-registry.vercel.app/r/input-extras.json
```

MultiSelect is fully controlled: pass `options`, `value` and `onValueChange`.
TagsInput adds on <kbd>Enter</kbd>, removes with <kbd>Backspace</kbd> or the badge ✕.
