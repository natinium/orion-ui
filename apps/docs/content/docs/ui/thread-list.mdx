## Usage

```tsx
import { ThreadList, ThreadListSearch } from '@/components/ui/thread-list'
```

```tsx
<ThreadList
  threads={threads}
  activeId={activeId}
  onSelect={setActiveId}
  onPinToggle={(id) => togglePin(id)}
  onRename={(id, title) => renameThread(id, title)}
  onDelete={(id) => deleteThread(id)}
>
  <ThreadListSearch />
</ThreadList>
```

Threads are sorted for you: pinned first, then by `updatedAt` descending.
Double-click a title to rename inline — Enter or blur commits, Escape cancels.
Deleting asks `window.confirm` before `onDelete` fires.

## API

| Prop | Type | Default |
|---|---|---|
| `threads` | `ThreadListThread[]` | required |
| `activeId` | `string` | — |
| `onSelect` | `(id: string) => void` | — |
| `onPinToggle` | `(id: string) => void` | — |
| `onRename` | `(id: string, title: string) => void` | — |
| `onDelete` | `(id: string) => void` | — |

`ThreadListThread`: `{ id, title, preview?, unread?, pinned?, updatedAt? }` —
`updatedAt` accepts an ISO string, epoch number or `Date`.

`ThreadListSearch` renders the filter field; it must sit inside `<ThreadList>`
and matches titles case-insensitively. Its `className` styles the field wrapper;
all other props forward to the native `<input>`.

## Accessibility

- Keyboard: Tab reaches the search field, thread rows, pin and delete buttons;
  focus is visible on every interactive element. While renaming, Enter commits
  and Escape cancels.
- IME: keydowns inside a composition (`isComposing`, or the legacy `keyCode`
  229) are ignored, so committing or cancelling a composition never commits or
  cancels the rename.
- Screen reader: rows are a native list; the active row is announced via
  `aria-current="true"`; pin buttons carry `aria-pressed` plus `Pin`/`Unpin`
  labels; delete buttons announce `Delete <title>`; an empty search result is
  announced through a `role="status"` region.
